Stop jumping between Employees, Attendance, Time Off, Expenses, Payroll, and Appraisals just to check the pulse of your workforce. This dashboard pulls everything into one screen and lets you act on it without leaving.

01 — Metrics

Every metric your team needs, at a single glance

Ten KPI cards pull live data from every HR module installed on your database. Attendance, leaves, payroll, expenses, contracts, performance reviews — each card has an animated counter, a contextual subtitle showing the breakdown, and a click-through drill-down to the filtered record list.

  • Animated counters with smooth transitions
  • Inline sparklines for attendance and growth trends
  • Click-through to filtered list views (Create button hidden by default)
  • Graceful hiding when optional modules (Payroll, Appraisal) are not installed
02 — Visualizations

Eight charts that tell the story

Powered by Chart.js 4.4 bundled locally — no external CDN calls. Every chart inherits your configured theme colors and adapts responsively to screen size. The department chart supports drill-through: click any bar to open the employees of that department.

  • Attendance trend over the last 14 days
  • Gender distribution (Odoo 19 sex field)
  • Employees by department, leaves by type, growth, expenses
  • Performance review pipeline and distribution
03 — Workflow

Approve requests without leaving the dashboard

A dedicated Approvals Center with three tabs — Leaves, Expenses, and Appraisals — lets managers act on pending requests with one click. The dashboard understands each module's actual workflow and advances state correctly.

  • Leaves: supports both single and double-validation flows
  • Expenses: smart Draft → Submitted → Approved in one click
  • Appraisals: state-aware buttons (Confirm / Mark Done / Reset)
  • Respects standard Odoo access rights — no privilege escalation
  • Auto-refresh of KPI counts after every action
04 — Drill-down

A 360° view of any employee

Toggle the Employee Spotlight and pick any team member from a searchable picker. See their profile, current contract version, manager hierarchy, leave balance, attendance, expenses, and latest payslip — all in one card.

  • Real-time search by name, job, or department
  • HR Version card with wage, contract dates, schedule
  • One-click print of the latest payslip
  • Per-employee leave, attendance, expense, payslip counts
05 — Customization

Match your brand without touching code

Seventeen theme fields cover every visual aspect of the dashboard — primary, secondary, and accent colors; a three-stop background gradient; six card category colors; text colors; glass opacity; blur intensity; and border radius. Upload your logo and watch the dashboard rebrand instantly.

  • 17 configurable theme fields, no SCSS edits required
  • CSS variables applied at runtime — instant preview on reload
  • Multiple configuration records — switch themes by activating
  • Custom logo, dashboard title, and subtitle
06 — Internationalization

Arabic + RTL out of the box

A complete Arabic translation ships in the box (158 strings, validated with msgfmt). The SCSS includes a dedicated RTL block that flips directional properties, embeds numbers as LTR within Arabic text (financial best practice), and adjusts typography for Arabic script.

  • 158 translated strings covering every UI element
  • Full RTL layout for Arabic, Hebrew, and other RTL languages
  • LTR numbers within RTL text (correct financial display)
  • Easy to add more languages — drop a new .po file

Built specifically for Odoo 19 Enterprise

This module uses Odoo 19's modern APIs throughout — OWL 3 components, the new RPC service, and the renamed HR models. It will not install on Odoo 17, 18, or earlier.

REQUIRED

  • hr
  • hr_attendance
  • hr_holidays
  • hr_expense

OPTIONAL

  • hr_payroll — enables Payslip KPIs
  • hr_appraisal — enables Appraisal section

Sections hide gracefully when optional modules aren't installed.

TECHNICAL

  • Odoo 19.0 Enterprise
  • Python 3.10+
  • OWL 3 component framework
  • Chart.js 4.4 (bundled)

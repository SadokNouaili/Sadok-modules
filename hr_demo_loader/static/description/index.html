What it generates

Eight ordered steps, where each one feeds the next.

Step What it creates
1 · Departments & Jobs Six departments and ~18 job positions, with a manager assigned per department.
2 · Employees ~25 employees with mixed gender, job titles, contact details and a reporting hierarchy.
3 · Contracts / Versions An hr.version record per employee with a realistic monthly wage.
4 · Attendance Check-in / check-out records over the last 14 days, weekends skipped, hours randomized.
5 · Time Off Four leave types, an approved allocation per employee, and pending + approved requests.
6 · Expenses Six categories and a set of expenses over the last 30 days, ~half submitted for approval.
7 · Appraisals optional If Appraisals is installed: spread across new / pending / done / cancelled, with managers and feedback.
8 · Payslips optional If Payroll is installed: three monthly payslips per employee, wages drawn from contracts.

Compatibility & dependencies

Built for Odoo 19.0. Requires the standard HR apps it writes to: Employees, Attendances, Time Off and Expenses.

Appraisals and Payroll are optional — their steps run automatically when installed and skip cleanly when not. No dashboard module is required.

Frequently asked questions

Will this affect my real HR data?

No. Every record is tagged with a [DEMO] prefix, and cleanup only removes tagged records. Your existing data is never modified or deleted.

What if I run the build more than once?

Nothing breaks. The builder is idempotent — it reuses existing demo records rather than duplicating them.

Do I need the Appraisals or Payroll apps?

No. They are optional — those steps run only if the apps are installed, and are skipped with a short note otherwise.

Who can run it?

Access is restricted to administrators (Settings access), so demo data cannot be generated by ordinary users by accident.

Can I remove everything afterward?

Yes. The Delete button removes all demo records in dependency-safe order and resets the on-screen counts to zero.
